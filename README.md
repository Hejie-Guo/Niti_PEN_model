# 镍钛疲劳寿命模型网页

基于仿真最大应变的 Coffin–Manson 型幂律—Weibull 概率寿命模型工作台。

## 页面功能

- 默认选择完整数据版统一模型，可切换到 2,000–8,000 次筛选版。
- 保留 WIN、BE、THK、LK 四个项目独立拟合模型。
- 支持寿命预测、应变反算、不同生存率的概率曲线和归一化曲线。
- 特征概率为生存率 36.7879%、累计失效概率 63.2121%，对应特征寿命 η。
- 提供留出验证、逐件原始数据及 PDF、Excel、CSV 下载。

## 使用方法

这是纯静态网页，无需安装前端依赖或执行构建。可在浏览器中打开 `dist/index.html`，也可在仓库根目录启动本地服务：

```text
python -m http.server 8000 --bind 127.0.0.1 --directory dist
```

然后打开 <http://127.0.0.1:8000/>。部署到静态托管服务时，将 `dist` 目录设为发布目录。

## 文件

- `dist/index.html`：页面入口。
- `dist/app.js`、`dist/model.js`：交互与寿命计算。
- `dist/data.js`：模型参数、原始记录及既有验证结果。
- `dist/styles.css`：样式。
- `dist/assets/`：页面使用的分析报告、数据与计算表。
- `test.cjs`：数值、数据完整性及下载资源检查。

安装 Node.js 后，在仓库根目录运行：

```text
node test.cjs
```

## 模型与数据说明

完整统一模型：

```text
N_P = 6211.0792 × (ε_max / 0.045)^(-2.680508) × [-ln(P)]^(1 / 2.682092)
```

ε_max 使用小数值，例如 4.5% 输入 0.045；P 为生存率，例如 90% 输入 0.90；N 的单位为循环次数。

完整保留 204 条原始记录，194 条有应变参与拟合，其中 191 条已失效、3 条为 20,000 次停机未失效的右删失记录。10 条缺应变记录保留，但不补造应变或计算确定预测。

验证采用 33 轮整组应变留出，每轮 32 个应变水平拟合、1 个验证。该验证不等同于新增批次的外部试验。参数为仿真最大应变下的经验拟合系数，不是经典塑性应变幅下的材料疲劳常数。
