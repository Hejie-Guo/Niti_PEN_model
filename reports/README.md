## 分组口径

最终完整模型使用33个不同应变水平、194条有应变记录。交叉验证每轮使用32个应变水平拟合，留出1个验证，共33轮，194件各获得一次留出预测。每行数据的验证轮次见对照表；在其余32轮中，该行参与拟合。

点误差使用191条已失效记录。3条20,000次停机未失效记录按右删失处理；另10条缺应变记录保留但不参与拟合或预测。报告和表格均保留这些区别。
